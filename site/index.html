The roadmap your coding agents keep.

Agents write roadmap.json while they work. roadmap-live turns it into a page you can look at: where the project stands, what is in progress, and what the agent is asking you. Nobody moves cards.

View on GitHub

One road, six stops.

From the first command to a page nobody has to update. Scroll, and the car drives it.

  1. 1

    Set up once

    In your project folder. It writes roadmap.json, AGENTS.md and a GitHub workflow. Existing files stay as they are.

  2. 2

    Your agent keeps the file

    Give it the rules once. From then on it marks what it works on, sets it done, answers your comments, and parks questions for you.

    Codex reads AGENTS.md by itself. For Claude Code, Cursor or Gemini CLI, put the line in their rules file.

  3. 3

    The page follows along

    Open it next to the terminal. Every change to the file shows up without a reload, with a timer on the item in progress.

  4. 4

    Pull requests join in

    Sync reads reviews, comments and merges and matches them to items. What reviewers still want becomes an open point. The included GitHub Action renders a static page you can share as a link.

    No API key needed. Sync uses Claude Code, Codex or Gemini CLI if you have one, or leaves the work for your agent.

  5. 5

    Only four things stand out

    Blocked, not on the roadmap, gone quiet, and a question for you. Everything else stays gray, so one look is enough.

    • BlockedCard payment with Stripe
    • Quiet 22 daysOrder queue for the kitchen screen
    • UnplannedCustomer loyalty points
    • QuestionPickup time in 15 or 30 minute steps?
    • In progressCheckout with pickup time
    • DoneMenu editor
  6. 6

    Answer from the page

    When the agent needs a decision, it asks on the page. Your answer goes into the same file, and the agent replies on its next run.
